Arduino Uno Calculator Project Pin Connections
==============================================

Keypad 4x4 Matrix Connections:
------------------------------

Rows (UPDATED: rowPins = {2, 3, A4, A5}):
- Row 0 -> Arduino Pin 2
- Row 1 -> Arduino Pin 3
- Row 2 -> Arduino Pin A4 (14)
- Row 3 -> Arduino Pin A5 (15)

Columns (from code: colPins = {4, 5, 6, 7}):
- Column 0 -> Arduino Pin 4
- Column 1 -> Arduino Pin 5
- Column 2 -> Arduino Pin 6
- Column 3 -> Arduino Pin 7

**NEW**: LCD Contrast (VO pin) -> Arduino **A0** (PWM pin for brightness control via analogWrite). Connect to LCD contrast pot wiper. Tune value 100-200 in code.

Key Layout (standard):
```
1  2  3  A
4  5  6  B
7  8  9  C
*  0  #  D
```

LCD 16x2 (HD44780 compatible) Connections:
-----------------------------------------
From code: LiquidCrystal lcd(rs=13, en=12, d4=11, d5=10, d6=9, d7=8)

- RS (Register Select) -> Arduino Pin 13
- EN (Enable) -> Arduino Pin 12
- D4 -> Arduino Pin 11
- D5 -> Arduino Pin 10
- D6 -> Arduino Pin 9
- D7 -> Arduino Pin 8

Power/GND:
- Vcc -> Arduino 5V
- GND -> Arduino GND
- **Contrast (VO)** -> **A0** (PWM)
- Backlight (A/K pins) -> 5V/GND via 220 ohm resistor on A

Notes:
- **Brightness fix**: A0 PWM in setup() - code now controls LCD contrast automatically.
- LCD.begin(8,2) → 8-column x 2-row mode (scrolling for longer text).
- Full code in src/CompleteCode.cpp.
- Upload: PlatformIO (`pio run --target upload`).

Wiring Diagram (text):
Arduino Pins 8-13 (right) for LCD data.
Pins 2-7, A4-A5 for keypad.
**A0 free for LCD contrast**.

Upload command: pio run --target upload
