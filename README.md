# Electronic-Calculator-Project-Based-on-Arduino

This is a Project where by Using Arduino, 4x4 Keypad, 16x2 LCD Display we disign a Programmable Calculator which can perform Arithmetic and Trignometric Operations.
Here when number is typed in keypad it is shown in the lcd. This can perform Operations according to the given code by pressing A,B,C and D in the Keypad.Check the Code to know the everyalphabit operation in the keypad.

The Code for this Project lies in the CompleteCode.c File which can be runned in Vs code by downloading Extension Platform IO and connecting Arduino to the PC.
Connection for this project can also be seen in calculator_pins.txt file.
